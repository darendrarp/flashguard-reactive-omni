⚡ FlashGuard — cross-chain stop-loss that fires in ~1 second

A price event on Unichain Sepolia is watched by a reactive contract on Reactive Lasna. The moment a stop-loss threshold breaks, it fires a callback to the ProtectedVault on Base Sepolia, which exits the position into stablecoins. No bot. No keeper. The reaction is on-chain. Built for the Reactive Omni Buildathon — track Every Second Counts.

Why this wins the track

  • Execution is the whole product: every exit is a real reactive transaction plus a real cross-chain callback, visible on three explorers.
  • Latency is measured, not claimed: the vault records full-loop latency on-chain (origin timestamp → callback block), and scripts/measure_latency.js cross-checks it from receipts.
  • Reactive does the real work: threshold evaluation, trigger dedup, and the callback decision all live in the reactive contract — the vault only executes authenticated callbacks.
  • Honest scope: a demo price feed (documented as such) with a production path to Chainlink/TWAP; mock tokens on testnet only.
